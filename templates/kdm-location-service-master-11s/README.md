# KDM Location Service Master 11S (KDM-LOC-11S)

## Overview
Standardized, high-converting 11-section master architecture for location-based service landing pages on King of Digital Marketing.

## Key Assets:
- **Skill Definition**: `.agents/skills/kdm-location-service-master-11s/SKILL.md`
- **Master ASPX Template**: `templates/kdm-location-service-template.aspx`
- **Automated Bulk Generator**: `templates/kdm-location-service-master-11s/builder.py`

## Running the Bulk Builder:
```bash
python3 templates/kdm-location-service-master-11s/builder.py
```
