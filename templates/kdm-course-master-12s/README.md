# KDM-COURSE-12S Master Course & Location Training Template

## Template Name
**`kdm-course-master-12s`** (Alias: **`KDM-COURSE-12S`**)

## Overview
This is the official high-converting 12-section standardized landing page master template for **King of Digital Marketing (KDM)** and **UIDMT (UpNext Institute of Digital Marketing & Technology)** course pages across different locations (e.g., Delhi, Allahabad/Prayagraj, Varanasi, Nehru Place, Noida, Gurgaon, Lucknow, Patna, Jaipur, Mumbai, Dubai, etc.).

## Reusable Placeholders in `template.aspx`
- `{{PAGE_SLUG}}`: Target aspx filename (e.g. `digital-marketing-course-noida.aspx`)
- `{{CITY_NAME}}`: Target City (e.g. `Noida`, `Lucknow`, `Varanasi`, `Gurgaon`)
- `{{CITY_NAME_ALT}}`: Alternate Name or prominent localities (e.g. `Sector 18`, `Gomti Nagar`, `DLF Phase 3`)
